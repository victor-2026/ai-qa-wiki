# Google Antigravity для QA (2026)

Источник: исследование Victor Ematin, Jul 2026.

## Позиционирование

Agent-First платформа от Google (запуск конец 2025, Antigravity 2.0 — май 2026).
В отличие от чат-ассистентов — полноценная платформа, где человек = менеджер команды агентов.

## Ключевые фишки для QA

### 1. Мультиагентная оркестрация
Параллельные агенты в разных workspace:
- Агент А: анализ кода и логов
- Агент Б: E2E тесты на Playwright
- Агент В: Browser-in-the-loop (проклик UI, сверка вёрстки)
- Manager View — единая панель управления

### 2. Multi-Surface Operation
Одновременный доступ к: редактору кода + терминалу + браузеру.
Пример: запустил сервер → открыл браузер → протестировал кликами → поймал ошибку → прочитал логи → исправил код.

### 3. Artifacts вместо логов
Наглядные артефакты: пошаговые тест-планы, скриншоты, видеозаписи browser recording.

### 4. Multi-Model Support
Базовая модель Gemini 3 Pro, но поддерживает Claude (Sonnet 4.5/5) и GPT-OSS.
Переключение модели на лету.

## Инфраструктура (4 формы)

| Форма | Для чего |
|-------|---------|
| Desktop App | Командный центр для локальных агентов |
| IDE | Полноценный редактор (VS Code / Cursor-like) |
| CLI | Лёгкий терминальный интерфейс |
| SDK | Python-библиотека для кастомной логики |

## Безопасность

Review Policy (настраивается):
- Planning Mode: агент строит карту → ждёт аппрув
- Request Review: показать код/команду перед выполнением
- Auto Execution / Fast Mode: полная автономия (только в изолированных контейнерах)

## Цены (2026)

После Antigravity 2.0 (май 2026) бесплатный тариф Individual $0 — жестко урезан.
Basic weekly rate limits сжигаются за 20-30 мин плотной работы, потом блокировка.

| План | Цена | Лимиты |
|------|------|--------|
| Individual (Free) | $0 | Недельные лимиты, хватает на 20-30 мин |
| Google AI Pro | $19.99/мес | Лимиты сброс каждые 5 часов |
| Google AI Ultra | $99.99/мес | x5 лимитов Pro, Gemini Spark |
| Google AI Ultra Max | $200/мес | x20 лимитов Pro, безлимит агентов |

## Альтернатива

OpenCode + OpenRouter — pay-as-you-go, cents за тестовый скрипт.
Antigravity в бесплатном режиме блокирует до понедельника после 30 мин работы.
