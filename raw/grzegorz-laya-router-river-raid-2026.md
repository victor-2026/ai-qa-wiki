## Post verbatim (condensed substance)

- Jev = model that doesn't write text: situation + question → choice/score/yes-no + calibrated probability. In practice a zero-shot classifier: fast, cheap, handy anywhere you pay an LLM just to pick an option. Category not new or exclusive.
- Open-weights same interface: Laya. Runs offline on MacBook: no network hop, no metered bill, data never leaves machine.
- Demo honesty rule: River Raid played from RAW SCREEN PIXELS only (plain code: plane/fuel/enemies/bridges by color → facts like "Fuel 62%, depot 55px ahead") - vs typical Jev demos fed engine state ("kind of cheating"). Model picks tactic (attack/refuel/dodge/cruise); code steers. ~10ms/call, ~150 decisions/sec, $0/hr, Wi-Fi off.
- Router use case: small cheap model in front of LLM API calls ("thanks" → small, "prove theorem" → big), decision in milliseconds, locally or as API routing pre-spend.
- Positioning: not an LLM replacement; a cheap gate in front of one. Gives a number, not a reason. Local beats hosted - every single time.
