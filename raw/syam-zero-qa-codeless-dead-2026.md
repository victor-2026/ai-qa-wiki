## Post substance

- Vendor pattern: many AI testing companies pitch "Zero QA engineers"; founders: elite universities, ex-CXOs, engineering pedigrees, millions raised; very few spent years in software testing.
- Dominant pattern: codeless × N. Made sense when automation code was expensive (frameworks, locators, CI, flakes, devices).
- Two sleeping giants: (1) code becoming cheap (agents generate/refactor/maintain in minutes) → economics of "codeless at all costs" breaks; future = MORE code by agents, not no code. (2) Test engineers write more code, not less; domain/risk/edge knowledge becomes executable leverage. "Won't forget who celebrated Zero QA engineers."
- Taqwright built on this bet.
