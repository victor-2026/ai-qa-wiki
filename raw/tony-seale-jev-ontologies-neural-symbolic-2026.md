## Post substance

- Jev launched Sep 15; HN launch thread ~2,000 points. Diogo Almeida (InstructGPT co-author) now pursues calibration objective (RLHF rewards agreement over accuracy; Jev: 80% should occur 80% of the time). No text generation: data + criteria + answer schema in, typed answers + probabilities out. $0.042/1M input, output free, 70-500ms.
- Someone still has to specify the decision: cheap decisions raise the value of precise bounded definitions. Ontology supplies it: class definitions → classification criteria; disjointness → exclusions; hierarchy → organized choices; described-level vocabulary → scale.
- Graph supplies evidence: ticket "service is slow" → linked service + contract + open incidents → application hands Jev the evidence. Ontology says what categories mean; graph supplies records; model judges. Same economy as token-saving: define once, retrieve facts, stop reconstructing business per call.
- System One/Two: Jev = fast judgment, no deliberation; slow work (category meanings, relations, evidence standards) lives in ontology/graph/humans. Neural-symbolic loop: continuous + discrete in synchrony.
