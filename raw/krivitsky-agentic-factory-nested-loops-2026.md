# Alexey Krivitsky — Agentic Factory: Nested Loops (Value Factory)

Source: https://www.krivitsky.com/post/value-factory-nested-loops (Jun 2, 2026). Author: Alexey Krivitsky (10X ORG, Org Topologies co-author).

Summary by Krivitsky. Three nested agentic loops ("Agentic Factory"):

- **Coding Factory (Level 1, innermost):** Coding Loop = Red → Green → Refactor. Agents optimize implementation quality through rapid feedback. Produces working tested code. Trap ("Ferrari Trap"): a Coding Factory alone optimizes toward "technically correct irrelevance" - more code doesn't mean more value; a faster engine pointed at a wall.
- **Feature Factory (Level 2, middle):** adds Feature Loop (on top of Coding Loop): Refine → Specify → Verify. Behaviors, workflows, executable specifications emerge. As of mid-2026 all current "agentic product development" systems describe this level. "Humans are required to operate the factories," directing and ensuring value.
- **Impact Factory (Level 3, outermost):** adds Impact Loop: Opportunity → Hypothesis → Impact. Continuously learns from real-world effects and redirects lower loops toward meaningful goals. Outer loop reshapes priorities based on measurable impact. "A common Feature Factory is not the final stage of agentic AI maturity - it is only the middle layer."

Each outer loop constrains and guides the inner loops, ensuring local optimization contributes to broader objectives rather than drifting into isolated efficiency. Truly adaptive systems need all three: code optimization, behavioral optimization, outcome optimization. (Krivitsky also notes: "AI amplifies whatever trajectory your org was already on" - a Feature Factory with no Impact Loop is that amplification made literal.)
