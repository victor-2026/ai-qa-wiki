Software testing is changing again.  
  
We're opening private beta access to CARBON, the first AI Agentic Verification Harness built to help coding agents test what they create.  
  
Signup for beta to try it out--and influence it: [**https://testers.ai/**](https://www.linkedin.com/safety/go/?url=https%3A%2F%2Ftesters%2Eai%2F&urlhash=y2fz&mt=ftAhNNNiPKnhXns3U1ezux7XTfRFj-t6QkIUUuuA3zIE-k8poq6HyJiSRxpLzywH6p-q5Y0CULxMmvD-C56zF86pfMowEtHZuVjp6uZgl23uXfFuGexPK0c&isSdui=true)  
  
A test framework provides libraries, conventions, and execution tools.  
  
A verification harness surrounds the entire job: it discovers what changed, understands the product and code, identifies risk, creates a prioritized test plan, executes through available tools, preserves evidence, learns from new widgets and flows, and explains how much confidence that evidence supports.  
  
A single command '/carbon' can run for hours on its own, doing weeks worth of wrok, with you in control.  
  
That distinction matters.  
  
AI coding agents can generate working software remarkably quickly. But speed creates a new bottleneck: How do we know the result is useful, safe, understandable, accessible, secure, and ready to ship?  
  
CARBON sits beside the coding agent and keeps asking those questions. And it can generate ai-native ocverage, but can control existing, non-AI test frameworks and existing tests.  
  
A typical run will:  
• Inspect the code, UI, APIs, existing tests, and recent changes  
• Verify that the feature delivers its intended business value  
• Generate functional, boundary, security, privacy, accessibility, performance, reliability, usability, and exploratory tests  
• Use realistic personas to attempt meaningful user journeys  
• Execute the highest-value tests first  
• Preserve screenshots, results, unknowns, and reproducible evidence  
• Explain why each test matters  
• Show what remains untested and what would most improve shipping confidence  
• Pause, resume, replay, and expand coverage without losing state  
  
The goal isn’t another pile of generated test scripts. It’s a durable verification loop around AI-generated software.  
  
CARBON is local-first, evidence-aware, and designed to operate inside coding-agent workflows. Humans still make the release decision. CARBON’s job is to make that decision far better informed.  
  
The private beta is for builders, testers, engineering leaders, and teams experimenting with AI-generated software.
