9 concepts that separate AI user from AI builder:

1. Agentic Loops — AI plans, acts, observes, reflects; loops until task done.
2. MCP (Model Context Protocol) — One interface connecting AI to tools (email, repos, databases, browsers).
3. Subagents — Break big problem into specialised tasks, run in parallel, merge results.
4. AI Gateway — One control plane for every model: auth, routing, rate limits, logs.
5. Inference Economics — Every token costs money. Smart caching cuts spend dramatically.
6. Evals — Test outputs against benchmarks before production.
7. Guardrails — Filter input/output to keep unsafe outputs and brand protected.
8. Observability — Traces, logs, metrics for production AI.
9. Context Engineering — Feed the right context from retrieval, memory, tools, history.

Thesis: "People spend months perfecting prompts and ignore the infrastructure, evaluation, and systems that power real AI products."

Useful as a framework for AI engineering maturity article — maps to existing work (context engineering skill, subagents via Playwright Agents/MAS, evals via llm-testing skill, guardrails via fault injection).
