# One Agent, One Job
## Summary
The concept of "one agent, one job" is a principle that aims to improve the reliability and performance of language models by assigning a single task to each agent, reducing context competition and degradation. This approach is inspired by the Unix philosophy, which emphasizes writing programs that do one thing well.

## Key Concepts
* **Context competition**: The idea that multiple instructions and tasks within a single agent's context can compete for attention, leading to degradation and non-determinism.
* **Degradation**: The decrease in performance and reliability of a language model as the context window grows and instructions compete.
* **Unix philosophy**: A software engineering principle that advocates for writing programs that do one thing well, rather than trying to do multiple things at once.
* **One agent, one job**: The principle of assigning a single task or job to each agent, reducing context competition and improving reliability.

## Practical Applications
* Splitting tasks into separate agents, each with its own folder and `CLAUDE.md` file, to reduce context competition and improve performance.
* Limiting the number of instructions and rules within an agent's context to minimize competition and degradation.
* Applying the Unix philosophy to language model design and development to create more reliable and efficient systems.
