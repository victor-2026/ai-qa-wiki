## 1.3 Delivering Value with LLMs

### Area of Effect Model

```
Human abilities → AI enhances → Human guides
```

**Key insight**: LLM amplifies human skills, doesn't replace them.

---

## 1.4 Being Skeptical

LLMs can **hallucinate** — produce confident but false information.

**Always verify** outputs!
