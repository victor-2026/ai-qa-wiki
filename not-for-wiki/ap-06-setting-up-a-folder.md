# Self-Containment in Agent Folders
## Summary
Self-containment is an engineering principle that ensures an agent's folder contains everything it needs to operate, and nothing else. This principle is crucial for efficient and focused operation, as it reduces the risk of errors and increases productivity. By keeping all necessary files and instructions within the agent's folder, the agent can quickly find what it needs and stay focused on its tasks.

## Key Concepts
* **Self-containment**: The principle of keeping all necessary files and instructions within an agent's folder.
* **Encapsulation**: A software engineering concept that bundles data with the instructions that operate on it.
* **Agent's memory**: The information that an agent needs to retain between sessions, which should be stored in a file within the agent's folder.

## Practical Applications
* Create a separate folder for each agent, containing all necessary files and instructions.
* Use a `CLAUDE.md` file to store instructions for the agent, including end-of-session routines.
* Maintain a `MEMORY.md` file to keep track of the agent's memory and update it at the end of each session.
* Keep the agent's folder organized and focused, avoiding unnecessary files and noise.
