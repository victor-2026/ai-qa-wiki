# From Chat to Agent
## Summary
The traditional approach to using language models like ChatGPT involves copying and pasting text, reading responses, and manually applying changes. However, this process can be inefficient and prone to errors. The emergence of agents, such as Claude Code, has addressed this issue by providing a program that can read files, edit them, and run commands, thereby streamlining the collaboration between humans and language models.

## Key Concepts
* **Agents**: Programs built around language models that can interact with files, edit them, and run commands, reducing the need for manual copying and pasting.
* **Language Models (LLMs)**: AI models that generate human-like text based on input prompts, but may introduce non-determinism and errors.
* **Tools**: Programs like ripgrep and ImageMagick that perform specific tasks, such as file search and image manipulation, and are integrated with agents to execute instructions.

## Practical Applications
* **Collaborative writing**: Agents like Claude Code can assist with writing articles by refining paragraphs, editing files directly, and keeping the latest version up-to-date.
* **File search**: Agents can search across files using tools like ripgrep, providing accurate results without relying on language models to generate text.
* **Command execution**: Agents can run commands using tools like ImageMagick, allowing users to perform tasks without needing to look up specific commands.
