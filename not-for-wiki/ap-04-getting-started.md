# Getting Started with Claude Code
## Summary
Getting started with Claude Code involves downloading and installing the desktop app, or using it in the terminal. The key to successful workflow automation is identifying a manual process that causes pain and inefficiency, and then using expertise in that process to create instructions for the agent.

## Key Concepts
* **Start with pain**: Identify a manual process that is time-consuming, prone to mistakes, and causes significant mental effort.
* **Expertise**: Only build workflows around processes that you are an expert in, to ensure precise definition of steps and validation of agent performance.
* **First engineering principle**: Only build workflows around things you already do well, to guarantee successful automation.
