# One Session, One Task
## Summary
The concept of one session, one task is an engineering principle that solves the problem of attention competition within a single agent. By dedicating each session to a single task, the agent operates in a smaller, cleaner context, making it easier to verify output and avoid mixing of unrelated data.

## Key Concepts
* **One session, one task**: Each session should have a single, well-defined task to avoid attention competition and context clutter.
* **Session unit**: A session is defined by a task, not a time period.
* **Context management**: The agent's context should be managed to prevent overload and ensure that only relevant information is loaded for each task.
* **End-of-session routine**: Saving progress, updating files, and closing the session is crucial to maintaining a clean context and avoiding degradation.

## Practical Applications
* When working with an agent, pick a single task and dedicate the session to it.
* Use the `/context` command to monitor the context window and prevent overload.
* Save results to files and end the session when the task is complete.
* Start a new session for each new task to maintain a clean context.
