# Full-Stack Verification with Playwright Agent and Database
## Summary
Full-stack verification is a testing approach that combines UI and database verification using a single AI agent. This approach utilizes Playwright and Postgres MCP servers to perform UI actions, extract data, and verify database consistency without requiring manual SQL queries.

## Key Concepts
* **MCP Servers**: Playwright and Postgres servers that enable the AI agent to interact with the UI and database.
* **AI Agent**: A single agent that executes a prompt to perform UI actions, extract data, and verify database consistency.
* **Read-only DB**: A database configuration that only allows read queries, ensuring data integrity.
* **Full-Stack Verification**: A testing approach that combines UI and database verification to ensure end-to-end functionality.

## Practical Applications
* **End-to-End Testing**: Full-stack verification can be used to test complex workflows, such as checkout processes, to ensure that both UI and database updates are correct.
* **Database Testing**: This approach can be used to test database schema, data consistency, and query performance without requiring manual SQL queries.
* **UI Testing**: Playwright can be used to automate UI testing, including actions such as clicking, filling forms, and navigating through pages.

## Related Topics
* **Buzzhive**: A testing framework that uses Jest and pg for database testing, which can be replaced or complemented with the MCP approach.
* **AI-экзоскелет для QA**: An AI-powered testing framework that can be used to automate testing workflows.
* **Database Testing Patterns**: Patterns such as read-only DB, timing guards, snapshot comparison, and extension to other MCP servers can be applied to improve database testing efficiency and effectiveness.
