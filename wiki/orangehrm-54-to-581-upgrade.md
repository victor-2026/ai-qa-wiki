# OrangeHRM 5.4 to 5.8.1 Upgrade: Challenges and Solutions
## Summary
The article discusses the upgrade process from OrangeHRM 5.4 to 5.8.1, highlighting the problems encountered and their respective solutions. The upgrade was performed on a local Docker setup on a MacBook with an Intel 2019 processor and 16GB RAM.

## Key Concepts
* **Docker Engine Issues**: The Docker Desktop engine failed to start, causing a timeout. This was resolved by installing `docker.io` directly in WSL 2 Ubuntu.
* **libllhttp Missing**: The `libllhttp.9.3.dylib` library was missing, preventing Node.js from starting. This was fixed by creating a symbolic link to the updated library.
* **Installer Redirect**: After upgrading the image, the installer redirected to `/installer/index.php`. This was resolved by running the `upgrade:run` command via the CLI.
* **Admin Password Issues**: The admin password stopped working after the upgrade. This was fixed by resetting the password directly in the database.
* **Test Failures**: Three local tests failed due to changes in the application's structure.
