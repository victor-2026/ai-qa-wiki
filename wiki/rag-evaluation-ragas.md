# RAG Evaluation Using Ragas
## Summary
RAG (Retrieval Augmented Generation) evaluation is a crucial aspect of testing LLMs (Large Language Models) that handle large context by breaking documents into chunks, indexing, and retrieving relevant parts. The Ragas evaluation framework provides a comprehensive approach to assessing RAG systems, addressing challenges such as non-determinism, qualification difficulty, and the need for objective metrics.

## Key Concepts
* **RAG**: Retrieval Augmented Generation, a technique that helps LLMs handle large context by breaking documents into chunks, indexing, and retrieving relevant parts.
* **Ragas Metrics**: A set of evaluation metrics, including Answer Relevance, Faithfulness, and Context Relevance, used to assess the performance of RAG systems.
* **RAG Customization Levers**: Parameters that can be adjusted to customize RAG systems, including retrieval algorithm, chunking strategy, embedding choice, and vector DB selection.
