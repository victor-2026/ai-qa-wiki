# WebTestBench: AI Agents for Web Testing
## Summary
WebTestBench is a research project that explores the use of AI agents for web testing. The project evaluated the performance of several AI models, including GPT-5.1, MiMo-V2-Flash, and Claude Sonnet 4.5, in testing 100 web apps across 7 categories. The results show that while AI agents can detect some defects, they are not yet reliable enough to replace human testing, with the best model achieving an F1 score of only 26.4%.

## Key Concepts
* **Computer-Use Agents (CUAs)**: AI agents that interact with web apps via screenshots and browser automation.
* **Vibe Coding**: Building web apps from natural language prompts using Large Language Models (LLMs).
* **Latent Logical Constraints**: Implied but not stated rules that are difficult for AI agents to detect.
* **Default-Correctness Bias**: The tendency of AI agents to judge a test as "Pass" when they are not sure.

## Practical Applications
* **Hybrid Approach**: Using human-written checklists with AI execution can improve testing efficiency and effectiveness.
* **Constraint Testing**: Identifying and testing implicit rules is crucial for detecting real bugs.
* **Two-Stage Decomposition**: Breaking down testing into two stages: what to test (human) and how to test (AI).
* **Cost Discipline**: Implementing cost-aware strategies, such as testing critical paths first and using tiered model selection, is necessary for efficient AI testing.
