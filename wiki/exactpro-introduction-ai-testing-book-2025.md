## Introduction to AI Testing – Guide to ISTQB CT‑AI Certification  
*Exactpro / BCS, 2025*  

**Authors:** Iosif Itkin, Iuliia Emelianova, Dmitrii Degtiarenko, Anna‑Maria Lukina  
**Publisher:** BCS Learning & Development (16 Sep 2025) – ISBN 978‑1780177182  
**Foreword:** Klaudia Dussa‑Zieger (ISTQB President)  

The book is a practitioner‑focused companion to the ISTQB Certified Tester Advanced – AI (CT‑AI) syllabus. It blends core AI/ML theory with concrete testing techniques, exam preparation material, and a rich set of visual examples. A public GitHub repository supplies runnable Jupyter notebooks, datasets, and reference solutions that extend the learning experience beyond the printed pages.

---

### Summary  

- **Target audience:** Testers new to AI, seasoned QA professionals dealing with AI‑enabled systems, and teams planning to embed AI into their testing pipelines.  
- **Structure:** 12 chapters aligned with the CT‑AI syllabus (e.g., AI fundamentals, data quality, model validation, monitoring) plus supplemental sections on enterprise AI adoption and ethical considerations.  
- **Exam support:** Each chapter ends with review questions; a full‑length mock exam is provided in the final chapter.  
- **Hands‑on layer:** The companion repo (github.com/exactpro/ai-testing-guide) contains three Jupyter notebooks covering data preprocessing, model‑driven test generation, and AI‑based result analysis, together with the “employee” dataset used in Chapter 9.  

---

### Key Concepts  

| Concept | How the Book Treats It | Relevance to CT‑AI |
|---------|-----------------------|-------------------|
| **AI/ML Foundations** | Concise explanations of supervised/unsupervised learning, neural networks, and model lifecycle. | Provides the knowledge base required by the “AI fundamentals” syllabus domain. |
| **Test Data Quality** | Techniques for bias detection, data drift monitoring, and synthetic data generation. | Directly maps to the “Data quality for AI” learning objective. |
| **Model Verification & Validation** | Use of statistical tests, confusion matrices, and explainability tools (SHAP, LIME) to assess model behavior. | Supports “Model verification” and “Model validation” topics. |
| **AI‑augmented Test Design** | Strategies for using generative AI to create test cases, oracle generation, and self‑healing scripts. | Aligns with “AI‑based testing techniques” in the syllabus. |
| **Monitoring & Governance** | Continuous performance tracking, alerting on drift, and compliance checklists. | Covers “AI monitoring and maintenance” learning outcomes. |
| **Ethics & Trustworthiness** | Discussion of fairness, accountability, and regulatory impacts on testing. | Mirrors the “Ethical considerations” section of CT‑AI. |

The book also introduces **mock‑exam tactics**, **visual decision trees**, and **real‑world case studies** from Exactpro’s financial‑services testing practice, illustrating how AI can be leveraged for high‑throughput, mission‑critical environments.

---

### Practical Applications  

1. **Exam Preparation** – Use the per‑chapter questions and mock exam to gauge readiness for the ISTQB CT‑AI certification.  
2. **Hands‑On Skill Building** – Run the Jupyter notebooks to practice data‑centric testing, generate AI‑driven test inputs, and evaluate model outputs on the supplied datasets.  
3. **Team Training** – Adopt the chapter‑wise slide decks (available on the GitHub repo) for internal workshops on AI testing fundamentals.  
4. **Process Integration** – Follow the “AI‑augmented test design” patterns to embed generative‑AI prompts into existing test‑automation frameworks, reducing manual test‑case authoring effort.  
5. **Governance Framework** – Apply the monitoring checklist to set up continuous validation pipelines for deployed ML models, ensuring compliance with industry regulations.
