# Black Box Testing (Тестирование «чёрного ящика»)

**Определение:** Тестирование без доступа к исходному коду, архитектуре или внутренней логике системы. Тестер работает только с входами и выходами, проверяя поведение по спецификации.

**Связь с мутациями:** Black-box mutation testing — внесение изменений без доступа к коду: изменение UI-элементов, подмена данных, модификация запросов. Проверяет, насколько тесты чувствительны к внешним проявлениям дефектов.
