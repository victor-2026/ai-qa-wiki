## Products (from their page)

- **Tetra OS** — "operating system for Scientific Intelligence": vendor-neutral data layer for labs (schemas, lineage, taxonomy, ontology). Thesis: AI apps only trustworthy on governed data ("an app that looks like it works" vs one you can trust with real lab data).
- **Tetra Data Foundry** — raw instrument outputs → standardized AI-ready datasets ("one searchable scientific memory"); IDS schemas (vendor-neutral representation); ELN wiring (e.g. Revvity Signals); visualization apps (dose-response curves).
- **CRO Connect** — onboarding assistant (maps new CRO file format <1h) + review app (parse/flag/route, one-click batch rejection); review time −80%; IND prep recovered 1–2 months.
- **QC plate review apps**, job monitoring (live), global search across ingestion fleet, real-time alerts (silent connectors, throughput drops — "minutes, not review time"), idle-app auto-shutdown, dark mode admin.
- **Tetra MCP + Tetra skills** — local-IDE agent building on Tetra OS (Claude Code with Tetra plugins in the FLIPR demo: plate layout ELN→instrument→results→ELN→visualization, no hand transcription). Blog thesis (verified): "not whether it can produce scientific software (it can) but the quality of the underlying foundation" — seven years of codified conventions (IDS core docs: org context, measurements, datacubes, sample links, PK/FK). Build inputs: prompt file + meeting transcript + sample data; Claude assembly + Jira tickets per component; mid-stream plain-English extension in minutes.
