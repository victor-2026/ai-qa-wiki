# Metamorphic Testing — Сравнение подходов

**Определение:** Метаморфное тестирование — метод для систем, где «правильный ответ» неизвестен (oracle problem). Вместо проверки конкретного результата проверяются **метаморфные отношения** между входами и выходами: если вход изменяется определённым образом, выход должен изменяться соответствующим образом.

**Связь с мутациями:** Мутация-тестирование проверяет, ловят ли тесты дефекты кода. Метаморфное тестирование проверяет, сохраняются ли инварианты поведения при изменении входов. Оба метода — alternatives для oracle problem.

**Пример:** Поисковый запрос → результаты. Если добавить фильтр → количество результатов должно уменьшиться или остаться равным (никогда не увеличиться).
