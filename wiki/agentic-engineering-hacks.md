# Хаки агентного инжиниринга — 22 приёма для эффективной работы с AI-агентами

Сводка 22 практик от инженера, который с помощью агентов выпустил last30days (27k★), Printing Press (4k★), Agent Cookie и стал топ-контрибьютором Python, Go, GStack и Paperclip.

## Ключевые концепции

### 1. Планирование как основа (Хаки 1-3)
- **plan.md** — при появлении идеи сразу `/ce-plan`, не начинать кодить
- **Планы для агентов** — сам plan.md почти не читать, спрашивать TLDR
- **План для плана** — не-инженерная работа (бизнес, стратегия) через тот же цикл

### 2. Инфраструктура сессий (Хаки 4-7)
- **Голосовой ввод** — Monologue/Wispr Flow на Mac, встроенная диктовка Apple на телефоне
- **cmux** — 4-6 параллельных вкладок (план, сборка, тестирование, баги)
- **Терминал → сразу агент** — новая вкладка открывается в Claude Code / Codex
- **Удалённое управление** — remoteControlAtStartup + AgentMail для почтового доступа

### 3. Режимы выполнения (Хаки 8-9)
- **YOLO-режим** — `skipDangerousModePermissionPrompt: true` (Claude), `approval_policy = "never"` (Codex)
- **Codex для сборки, Claude для планирования** — Codex: reasoning xhigh + fast mode; Claude: xhigh, fast mode выключен

### 4. Исследование и контекст (Хаки 10-11)
- **last30days** — исследование темы перед планированием (Reddit, X, YouTube, HN)
- **Granola** — сырые расшифровки встреч → `/ce-plan`, без предварительного summarisation

### 5. Человек в цикле (Хак 12)
- **Человеческий сигнал** — агенты дают объём, человек — вкус, направление, реакцию
- Задача человека — быть сигналом, не делать работу руками

### 6. Форматы вывода (Хаки 13, 16)
- **HyperFrames** — видео как HTML: script.md → MP4
- **Proof** — отправка plan.md/спек коллегам с комментариями

### 7. База знаний (Хак 14)
- Заметки = база знаний агента: Bear CLI, Obsidian, gbrain, supermemory
- Накопительный эффект — каждая сессия умнее предыдущей

### 8. Автоматизация процессов (Хаки 17-18)
- **Собственные скиллы** — всё, что делается чаще двух раз
- **Open source** — контрибьюция в любимые проекты через тот же цикл

### 9. Железо и удалёнка (Хаки 15, 19)
- Mac mini + Mosh (SSH), Tmux (самолёты), Hermes/OpenClaw
- M5 Max 64GB, павербанк Anker, зарядка в Tesla

### 10. CLI для всего (Хак 20)
- **Printing Press** — фабрика CLI для любых сервисов (Tesla, Instacart, ESPN, Alaska Airlines)
- **Agent Cookie** — передача браузерной сессии CLI

### 11. Психология (Хак 21)
- ИИ-психоз — агенты не уменьшили работу, а создали новую зависимость
- Делать перерывы, трогать траву, строить то, что нужно (даже только себе)

## Практическое применение

- **Для QA-инженеров:** цикл исследуй → планируй → строй применим к тестовой автоматизации
- **Для AI-агентов:** plan.md как поводок против лени LLM
- **Для контекстного бюджета:** план — контрольная точка, переживающая переполнение контекста
