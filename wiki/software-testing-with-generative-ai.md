# Software Testing with Generative AI
## Summary
Software Testing with Generative AI is a book that explores the application of generative AI in software testing. The book is divided into three parts: Mindset, Technique, and Context, covering topics such as prompt engineering, AI-assisted testing, and customized LLMs. Readers will learn how to improve test quality, construct test automation, and formulate new ideas during exploratory testing using AI.

## Key Concepts
* **Prompt Engineering**: The process of designing and optimizing prompts to effectively interact with large language models (LLMs).
* **AI-Assisted Testing**: The use of AI to support testing activities, such as test planning, test data generation, and UI automation.
* **Customized LLMs**: The process of fine-tuning LLMs with business domain knowledge to create customized models for specific testing contexts.
* **RAG (Retrieval-Augmented Generation)**: A technique that combines retrieval and generation capabilities to improve the performance of LLMs.

## Practical Applications
* Improving test quality with AI
* Constructing test automation with AI support
* Formulating new ideas during exploratory testing using AI
* Using AI for test design and improving testability
* Maximizing output with prompt engineering
* Creating custom LLMs for business needs
