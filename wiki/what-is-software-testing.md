# Software Testing
## Summary
Software testing is a continuous process that spans the entire software development life cycle (SDLC), aiming to assess the quality of software and reduce the risk of failure. It involves challenging assumptions, verifying, and validating software against different artifacts throughout the cycle.

## Key Concepts
* **Testing is continuous**: It's not just a step, but an ongoing process that occurs throughout the SDLC.
* **Verification and validation**: These activities happen repeatedly across the whole cycle, including static testing, reviews, and analysis.
* **Testing vs QA**: Testing is a specific software evaluation, while QA focuses on process improvement and preventing defects.
* **Testing as a role and act**: Anyone can perform testing activities, regardless of their role, and testing is not limited to executing scenarios.

## Practical Applications
* **Integrate testing into the SDLC**: Incorporate testing into every stage of software development, from requirements analysis to deployment and monitoring.
* **Challenge assumptions**: Encourage a culture of questioning and challenging assumptions throughout the development process.
* **Involve multiple roles**: Encourage collaboration between testers, developers, and other stakeholders to perform testing activities.
* **Use various testing techniques**: Utilize static testing, dynamic testing, code reviews, and static analysis to ensure thorough testing.

## Related Topics
* **Verification vs Validation**: Understanding the difference between verifying that software meets specifications and validating that it meets user needs.
* **Definition of Done**: Establishing clear criteria for when software is considered complete and ready for release.
* **QA, QC, and Quality**: Exploring the relationships between quality assurance, quality control, and overall software quality.
* **Shift Left Testing**: Moving testing activities earlier in the SDLC to catch defects and issues sooner.
