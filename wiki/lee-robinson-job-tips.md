# Lee Robinson - Как выделиться при поиске работы

**Source:** Lee Robinson (@leerob), VP Product at Cursor
**Original:** Twitter/X thread
**Context:** Former Head of Developer Experience at Vercel (Next.js creators)

## 11 советов от Lee Robinson

### 1. Резюме = 1 страница
- Если нужно больше — дайте ссылку на личный сайт
- Не нужно 10+ пунктов на каждое место работы

**Почему:** Наниматели не будут тратить 20 минут на каждую заявку.

### 2. Личный сайт = выделит вас среди 90%
- Ссылка на сайт с хоть каким-то замыслом
- Показывает, что вы умеете делать больше, чем код

**Пример хорошего:** portfolio с проектами, блог, о себе

### 3. Почистите X перед подачей
- Кажется очевидным, но люди постят дикие вещи
- HR может проверить ваш профиль

**Действие:** Проверьте последние 50 постов.

### 4. GitHub без MySpace-стиля
- Не нужно 100 бейджиков и картинок
- Смотрите на код и способность строить интересное

**Антипаттерн:** README профиля = витрина тщеславия

### 5. Кастомизируйте под компанию
- Стартап: опыт в стартапах важнее университетских курсов
- FAANG: академический бэкграунд может помочь пройти ATS

**Совет:** Одно резюме не подходит для всех.

### 6. Упоминайте AI/агентов в резюме
- Разработка меняется — это должно быть отражено
- Даже если не работаете в AI-компании

**Пример:** "Использую Claude/Copilot для code review", "Экспериментирую с AI-агентами"

### 7. Относитесь к LinkedIn серьёзно
- Большинство разработчиков на X, но HR пересылают LinkedIn внутри компании
- Это основной канал рекомендаций

**Действие:** Профиль должен быть завершённым.

### 8. Покажите уникальные интересы
- Подборка книг + почему понравились
- Что-то написанное
- Фильмы/музыка, которые зашли

**Зачем:** Люди хотят работать с теми, кто им нравится.
"О, мне тоже нравится [книга]!" = начало разговора.

### 9. Не используйте AI для написания CL/CV
- Особенно очевидно в AI-компании
- Можно для идей/формулировок, но пишите от руки

**AI-фразы-триггеры:** "Synergy", "Leverage", "Game-changer"

### 10. Никаких фотографий
- Оставьте их для соцсетей
- Фокус на навыках и опыте

### 11. Качество > Количество
- 3 хороших проекта vs стена из 27 AI-слопа
- Продуманные, детальные, интересные проекты

## Ключевая мысль

> Нанимающие менеджеры получают сотни/тысячи заявок. Они не будут тратить 20 минут на каждую.

**Вывод:** Убирайте шелуху, переходите к сути.

## Чеклист по Lee Robinson

- [ ] Резюме на 1 страницу (или ссылка на сайт)
- [ ] Личный сайт/portfolio
- [ ] X почищен
- [ ] GitHub в нормальном стиле
- [ ] Резюме кастомизировано под тип компании
- [ ] Упомянуты AI/агенты
- [ ] LinkedIn заполнен
- [ ] Показаны уникальные интересы
- [ ] CL написан от руки (не AI)
- [ ] Нет фотографий
- [ ] 3 качественных проекта, не 27 так себе
