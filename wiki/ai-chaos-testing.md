# AI for Chaos Testing
## Summary
Chaos testing is a methodology that introduces unexpected events to assess system behavior. AI can be leveraged to generate diverse chaos testing scenarios, saving time and mental effort. By combining AI's ability to analyze complex systems with human validation and execution, testers can ensure their systems are resilient and reliable.

## Key Concepts
* **Chaos testing**: introducing unexpected events to assess system behavior
* **AI in chaos testing**: generating diverse testing scenarios, analyzing complex systems, and providing hallucinations (diverse options) to filter
* **Human role**: filtering ideas, reviewing plans, reviewing and approving, executing and observing
* **Key principle**: AI generates diversity, humans validate and execute

## Practical Applications
Chaos testing can be applied to various components, including:
* **Network**: latency injection, random server outages, bandwidth exhaustion
* **Ingress Controllers**: latency in request routing, terminate controllers, DDoS simulation, resource exhaustion
* **Application Layer**: service communication latency, individual service outages, CPU/memory/disk exhaustion, disable dependencies
* **Database Layer**: unavailability, slow queries, corruption, connection limit exhaustion, disk space exhaustion
* **API Gateway**: request processing latency, gateway downtime, DDoS simulation, CPU/memory exhaustion
* **External Services**: read/write latency, bucket/service unavailability, burst traffic, message duplication
