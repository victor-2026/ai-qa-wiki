## What Was Covered

Practical introduction to Claude as an AI partner (not just chatbot). Topics:

1. **Prompting techniques** - effective ways to communicate with Claude
2. **Projects** - organizing work in Claude
3. **Artifacts** - generating and using outputs
4. **Skills** - extending Claude's capabilities
5. **Connectors** - integrating external tools
6. **MCP (Model Context Protocol)** - tool integration standard
7. **Research Mode** - deep research capabilities
8. **Extended Thinking** - complex reasoning
9. **Claude Code** - coding assistant
10. **4D Framework for AI Fluency**

## 4D Framework for AI Fluency

Key framework from the meetup for responsible AI use:

| D | Concept | Description |
|---|---------|-------------|
| **Delegation** | When to use AI | Deciding what tasks to hand to AI |
| **Description** | How to communicate | Clear task specification and prompts |
| **Discernment** | How to evaluate | Assessing AI-generated output quality |
| **Diligence** | Taking responsibility | Owning the final result |

## Relevance for QA/QE

- **MCP** = standard for tool integration (relevant to agent testing)

- **4D Framework** = governance model for AI use (relevant to Article 26/27)
