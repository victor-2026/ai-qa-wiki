# CodeScene: Making Legacy Code AI‑Ready – Benchmarks on Agentic Refactoring (2026)

**Source:** https://codescene.com/blog/making-legacy-code-ai-ready-benchmarks-on-agentic-refactoring  
**Authors:** Adam Tornhill, Markus Borg (CodeScene)  

---

## Summary
Enterprises are racing toward agentic AI, assuming that faster code generation will boost productivity. CodeScene’s latest benchmarks show that the real obstacle is **legacy code quality**. The industry average Hotspot Code Health sits at **5.15 / 10**, while a score of **9.0** is needed for human‑readable code and **9.5** for reliable AI‑driven modifications.  

In a controlled experiment, raw Claude Code refactoring was compared with the same agent guided by CodeScene’s **CodeHealth MCP** (Metric‑Controlled Prompt). Across 25 k competitive‑programming files, MCP‑guided agents delivered **2–5×** larger Code Health gains, performed far more structural changes (e.g., Extract Method), and reduced shallow edits. The results demonstrate that **guidance, not raw model size, is the key to unlocking AI‑friendly code**.

---

## Key Concepts

| Concept | What it means | Why it matters |
|---------|---------------|----------------|
| **Code Health** | A composite metric (0‑10) quantifying complexity, duplication, readability, and responsibility distribution. | Predicts delivery speed, defect density, and AI‑induced bug risk. |
| **AI‑Ready Code** | Code Health ≥ 9.5, where LLM agents can propose deep, safe refactorings without exploding token usage. | Guarantees that agentic tools add value rather than introduce new bugs. |
| **Metric‑Controlled Prompt (MCP)** | A feedback layer that injects concrete Code Health diagnostics into the LLM’s prompt, turning a vague “refactor” request into a targeted plan. | Turns agents from conservative, shallow editors into strategic refactorers. |
| **Raw vs. Guided Refactoring** | *Raw*: Claude Code operates on its own training knowledge. <br>*Guided*: Claude Code receives a CodeHealth review and iteratively re‑measures progress. | Guided runs achieved 2‑5× higher Code Health improvements and 3× more structural refactorings (Extract Method 21 k vs 7.5 k). |
| **Refactoring Types** | *Structural* (Extract Method, Split Class) vs. *Shallow* (Rename Variable). | Structural changes shift the codebase toward AI‑readiness; shallow edits have limited impact. |
| **Token Savings** | Healthier code reduces the number of edit cycles and the amount of source material the model must process. | Early data suggests ~50 % fewer tokens for comparable tasks, lowering cost and latency. |

## Practical Applications

### 1. Enterprise Adoption Roadmap
1. **Baseline Assessment** – Run `code_health_review` across the codebase to obtain a numeric baseline and pinpoint hotspots.  
2. **Target Setting** – Aim for a Code Health ≥ 9.5 in high‑risk modules before deploying agentic coding assistants.  
3. **MCP Integration** – Wrap the LLM call with the CodeHealth MCP payload, feeding the agent specific complexity drivers and smell reports.  

### 2. Continuous Refactoring Loop
- **Iterate**: Agent proposes a refactoring plan, applies changes, and re‑runs the CodeHealth review.  
- **Validate**: Automated unit tests verify functional correctness after each iteration.  
- **Stabilize**: The loop continues until the health target is reached, after which the agent can safely handle feature work.  

### 3. Cost & Productivity Gains
- **Delivery Speed** – High Code Health correlates with faster cycle times and lower defect rates (Code Red research).  
- **AI Correctness** – AI‑generated patches exhibit fewer regressions when the underlying code is healthy.  
- **Token Economy** – Roughly 50 % reduction in token consumption translates to lower LLM service bills and quicker responses.  

### 4. Scaling Refactoring Efforts
- Deploy the MCP‑guided workflow as part of CI/CD pipelines, ensuring every merge maintains or improves Code Health.  
- Use the benchmark data (e.g., Extract Method count) to set quantitative KPIs for refactoring teams.  

---

## Takeaway
Legacy code quality is the primary bottleneck for realizing the promised productivity of agentic AI. By coupling LLM agents with a **CodeHealth MCP**, enterprises can transform low‑quality codebases into AI‑friendly assets, achieving measurable health gains, deeper structural improvements, and tangible cost savings.
