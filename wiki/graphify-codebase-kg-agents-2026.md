## Graphify – Turning a Codebase into a Queryable Knowledge Graph for Agents  

**Author:** Olimpiu Pop (InfoQ) – 2026‑09‑23  
**Project:** [Graphify‑Labs/graphify](https://github.com/Graphify-Labs/graphify) (MIT + Apache‑2.0, open‑source since Apr 2026)  

### Summary  
Graphify builds a multimodal knowledge graph (KG) that fuses a repository’s abstract syntax trees (via **tree‑sitter**), documentation, and embedded images. The resulting KG can be queried directly or through a **Multimodal Context Provider (MCP)**, giving autonomous coding agents instant access to “define‑once, retrieve‑anywhere” facts. Early benchmarks (LOCOMO, QA, LongMemEval‑S, ERPNext key‑fact) show recall@10 ≈ 0.5 and QA accuracy ≈ 45 %, while token‑reduction claims remain to be independently verified. The authors acknowledge that for medium‑size projects traditional grep‑style search still outperforms Graphify, positioning the tool as a **complementary** rather than a universal replacement.

### Key Concepts  

| Concept | What it means | Why it matters |
|---------|---------------|----------------|
| **Multimodal KG** | Nodes represent code entities, markdown sections, PDFs, and images; edges capture syntactic, semantic, and visual relationships. | Enables agents to reason across source, docs, and UI screenshots without separate parsers. |
| **AST + Tree‑Sitter** | Full‑fidelity abstract syntax trees are extracted for every language supported by tree‑sitter. | Guarantees precise, language‑aware navigation (e.g., function signatures, inheritance). |
| **Community Detection** | Graph clustering groups related entities (e.g., a feature module, its docs, and UI mock‑ups). | Provides higher‑level “concept buckets” that agents can query instead of low‑level tokens. |
| **Multimodal Context Provider (MCP)** | A thin API layer that translates natural‑language queries into KG traversals and returns concise context blocks. | Allows plug‑and‑play integration with existing RAG pipelines or custom agents. |
| **Benchmark Scaffold** | Standardised tests (LOCOMO recall@10, QA accuracy, LongMemEval‑S, ERPNext key‑fact) used to measure context quality. | Offers a reproducible yardstick for future KG‑based tools and for evaluating RAG improvements. |
| **Installation Simplicity** | Distributed via **uv** wheels; supports macOS, Windows, Ubuntu. | Lowers entry barrier for teams experimenting with agentic coding. |

### Practical Applications  

1. **Agent‑Driven Code Exploration** – An autonomous debugging agent can ask “What UI components are affected by `Order.process()`?” and receive a concise, cross‑modal answer that includes relevant source files, design docs, and screenshot snippets.  
2. **Context‑Optimised Retrieval‑Augmented Generation (RAG)** – By feeding the MCP’s distilled facts into LLM prompts, developers reduce token usage while preserving essential information, improving both cost and latency.  
3. **Compliance & Auditing** – Security auditors can query “All data‑flow paths from `UserInput` to DB writes” and obtain a graph‑based trace that includes code, policy docs, and architecture diagrams.  
4. **Onboarding & Knowledge Transfer** – New hires can ask natural‑language questions about a feature and instantly receive a multimodal summary, shortening ramp‑up time.  
5. **Tool‑Chain Integration** – Graphify can serve as the “context plane” in larger ecosystems such as Qodo’s Software Map (risk‑vs‑context layers) or VerdictGate’s evaluation harness, providing a shared factual backbone.

### Adoption Considerations  

* **Performance** – For repositories under ~200 k LOC, grep remains faster; Graphify shines on large, heterogeneous codebases where cross‑modal links matter.  
* **Version 2 Roadmap** – Planned deeper parser intelligence (type inference, data‑flow analysis) may close the speed gap and improve recall.  
* **Community Feedback** – Early adopters report friction in initial setup but praise the unified view once the KG is built.
