# GPT Image 2 — Research Before Generation

## Hidden Superpower

GPT Image 2 has a capability most people don't know about: the model **researches the topic in the web before generating** the image.

Instead of detailed text description, you can write:

```
research [specific topic], then generate image
```

The model finds information, understands details, then creates.

---

## How It Works

### Before (Old Approach)
```text
Draw a classic car VAZ-2101 with chrome bumpers, 
yellow headlights, specific proportions...
```

**Problem:** You must describe every detail manually.

### After (Research Mode)
```text
research VAZ-2101 "Zhiguli", then draw it as studio photo
with dramatic lighting, 3/4 rear angle
```

**Result:** Model finds details about "Kopeyka" itself — proportions, headlights, chrome bumpers — and generates accurately.

---

## What This Means

| Before | After |
|--------|-------|
| Detailed manual description | Just name the subject + style |
| You know all specifics | Model researches unknown details |
| Works for generic topics | Works for specific objects |

---

## Best Use Cases

- Specific car models (VAZ-2101, Toyota Celica, etc.)
- Architectural buildings (Taj Mahal, Sagrada Familia)
- Interior items (Eames chair, specific furniture)
- Historical objects (Ford Model T, typewriters)
- Technical equipment (specific machines)

**The more specific the object, the bigger the difference.**
