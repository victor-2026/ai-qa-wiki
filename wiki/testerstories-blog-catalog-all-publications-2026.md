## Key Strengths & Gaps (for QA/QE)

**Strengths:**
- Densest hands-on **DeepEval RAG evaluation** series among personal blogs (Faithfulness, Contextual Precision/Recall/Relevancy, G-Eval, conversational eval, synthesis) — grounds abstract metrics in RAG pipeline with code.
- Bridges **knowledge graphs & ontologies** (Z-Machine spec → ontology → implementation → story) — useful for agentic context layer (Martin Fowler's domain model + Zalando's semantic layer).
- **Causality / hallucination-of-hallucinations** posts test trustability when cause/effect matters — complements Zalando's observability and Postman's QE gaps.

**Gaps / Watch-outs:**
- Single-author, philosophical tone — not benchmark-driven like Kiro 406K diagnostics or Zalando 250-team metrics; more narrative, less statistical.
- Heavy Feb-Apr 2026 cluster — may require sequential reading; standalone value for RAG eval is high, but isolated posts assume prior series context.
