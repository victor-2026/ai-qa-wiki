## Top 10 Must-Read for QA/QE Engineer — Summaries

> Each summary 60-90 words, QA lens. Full 90-120-line analysis in linked wiki page.

### 1. Introducing Kiro Crew (Aug 4) — Multi-Agent Orchestration, Open Source
Open-source platform (ex-Amazon MeshClaw) for orchestrating multiple AI agents with human oversight. ACP standard, defense-in-depth security, self-learning memory, scheduling/webhooks, Apps SDK. 39K Amazon builders validate at scale.
**QA:** Pattern for federated QA agents (API audit, PBT, regression) vs monolith; observable orchestration = auditable evidence.
**Links:** [wiki → Kiro Crew](kiro-crew-multi-agent-orchestration-open-source-2026.md) · [original](https://kiro.dev/blog/introducing-kiro-crew/)

### 2. Continuous Prompt Evaluation (Aug 21) — LLM Judges and Live Signals
4-stage cycle (Diagnose → Design → Test cohorts → Evaluate) using LLM-as-judge on 15 behavioral dimensions (task completeness, claim accuracy, verification). Isolated + combined cohorts detect interactions; re-validation required per model upgrade. CLI -32% behavioral issues, IDE -54% style mismatches.
**QA:** Apply same evidence-required rubric to agent-generated tests; reuse complaint cases as regression suite.
**Links:** [wiki → Prompt Evaluation](kiro-continuous-prompt-evaluation-llm-judges-2026.md) · [original](https://kiro.dev/blog/continuous-prompt-evaluation/)

### 3. Are AI Coding Agents Actually Getting Better? (Aug 26) — Agent Quality Metrics
406K diagnostics invocations, 1.5M conversations, 7 Claude models. Errors/file converging to ~1.2; invocation rate only 3-22% (need mandatory gating); newer models check ~2 files/invocation (cross-file regressions); unresolved imports dominate 30-58%; test files 3-4x harder than source; Java 26.7% vs Python 4%.
**QA:** Gate agents on diagnostics clean; budget more review for Java/test code; enforce impl+test joint validation.
**Links:** [wiki → Diagnostics Over Time](kiro-diagnostics-over-time-agent-quality-2026.md) · [original](https://kiro.dev/blog/diagnostics-over-time/)

### 4. Property-Based Testing Caught a Security Bug (Dec 18) — PBT in Practice
SDD round-trip property (`save → load == key`) with fast-check 100 iterations found `__proto__` prototype-pollution bug on trial #75; shrinking isolated provider as cause; fix `Object.create(null)`. Human review missed it; PBT injected institutional edge corpus.
**QA:** Template: round-trip properties for storage APIs; don't hand-pick edges, use generators; run 100+ iterations in CI.
**Links:** [wiki → PBT Security Bug](kiro-property-based-testing-security-bug-2026.md) · [original](https://kiro.dev/blog/property-based-testing-fixed-security-bug/)

### 5. From OpenAPI to Test Suite in Seconds (Jun 25) — API Test Generation
Spec as source of truth: Kiro generates axios test client + Express mock server + config toggle + vanilla runner from OpenAPI. Steering file codifies team standards; mock+live toggle surfaces spec drift. Quality: integration tests with multi-request chains (POST-DELETE-GET 404), self-sufficient fixtures.
**QA:** Steering = contract-testing standards; headless CI regeneration closes spec-test drift gap.
**Links:** [wiki → OpenAPI to Tests](kiro-openapi-to-testsuite-2026.md) · [original](https://kiro.dev/blog/from-openapi-swagger-to-test-suite-in-seconds-with-kiro/)

### 6. The Bug Fix Paradox (Feb 19) — Why AI Agents Break Working Code
Agents 2x more likely to add guard clauses; drift from intent. Solution: property-aware evolution with bug condition C (partition) + postcondition P → Fix property `C ⟹ P` and Preservation `¬C ⟹ unchanged`. BST delete example + RocketMQ leak (key mismatch). Hypothesis falsifiable via PBT before patch; one-line fix validated both suites.
**QA:** Require bug ticket to define C/P; split fix vs preservation suites; differential oracle = unfixed behavior.
**Links:** [wiki → Bug Fix Paradox](kiro-bug-fix-paradox-2026.md) · [original](https://kiro.dev/blog/bug-fix-paradox/)

### 7. Root Cause in 33 Seconds (Apr 16) — CLI Automation for Debugging
Generalist Kiro CLI diagnosed perf bottleneck in 10 autonomous turns: parser re-init every call → 80% CPU; fix shared cache cut P99 30m → <1m, saving 4 years compute/month (381 pkgs × 550K builds). Tools: `generate_codebase_overview`, `search_codebase_map`, subagent delegation, `fs_read/write`.
**QA:** Feed structured perf/logs as context; use overview tools before deep dive; gate fix with human validation.
**Links:** [wiki → Root Cause 33s](kiro-root-cause-33s-2026.md) · [original](https://kiro.dev/blog/root-cause-in-33s/)

### 8. Planview Saves 40+ Hours per Audit (Apr 10) — SOC 2 Compliance Automation
Custom `soc2-compliance` agent with scoped read-only AWS tools (`autoAllowReadonly`, `allowedServices` IAM/CloudTrail/Config etc.), resources = policies/audit YAMLs. Prompt → timestamped CC6.1 evidence across 34 S3 buckets (encryption, public access, logging) + repeatable scripts. Result: 40h saved, 60% efficiency, 1-1.5 SDE sprints reclaimed, on-demand evidence.
**QA:** Pattern for evidence agent: least-privilege read-only, prompt → report + script.
**Links:** [wiki → SOC 2 Planview](kiro-soc2-planview-automation-2026.md) · [original](https://kiro.dev/blog/automating-soc-2-compliance/)

### 9. Kiro and Snyk Multi-Layered Security (Jul 20) — Security Guardrails
Defense-in-depth via Snyk MCP Server: natural-language scan (`Scan this directory`), AIBOM (`snyk aibom`), Toxic Flow Analysis (prompt injection), Agent Hooks (scan on save). Covers code/dependency + AI-specific threats; auditable logging for compliance. Customer tracks AI + human code, guards against Tool Poisoning/Rug Pulls.
**QA:** Add scan to DoD, hooks for shift-left, extend QA to prompt-injection negative tests.
**Links:** [wiki → Snyk Guardrails](kiro-snyk-guardrails-2026.md) · [original](https://kiro.dev/blog/kiro-and-snyk-guardrails/)

### 10. How We Learned to Trust an AI Agent (Aug 21) — Trust + Incident Triage
Frontier team lets CLI triage prod tickets: 2:33 AM alarm → 2:46 AM (13m35s) diagnosis with ruled-out hypotheses, evidence-linked queries. System: stock CLI + markdown steering + MCP ReadOnly + 107 skills (progressive disclosure) + dispatcher spawning headless sessions. Flywheel: corrections → lessons, investigations → archive, agent drafts skills (human review). 250 investigations/mo, median 13.6m, cost ~9 subscriptions.
**QA:** 96.9% reads gated writes; require ruling out competing hypotheses before conclusion; concise visible post + full worklog.
**Links:** [wiki → Trust Agent Triage](kiro-trust-agent-triage-2026.md) · [original](https://kiro.dev/blog/trust-agent-triage/)
