# Property-Generated Solver: PBT for LLM Code Generation
## Summary
The Property-Generated Solver (PGS) is a novel approach to ensuring the correctness of code generated by Large Language Models (LLMs). By utilizing two collaborative LLM agents, a Generator and a Tester, PGS leverages Property-Based Testing (PBT) to validate high-level properties and invariants that the generated code must satisfy. This approach has shown a 23.1%-37.3% relative improvement over traditional Test-Driven Development (TDD) methods on code generation benchmarks.

## Key Concepts
* **Property-Based Testing (PBT)**: a testing framework that validates properties and invariants rather than specific inputs.
* **Cycle of self-deception**: a phenomenon where tests share flaws with the code they are meant to validate.
* **Property**: a high-level rule that the code must satisfy, such as "output is always non-negative".
* **Generator**: an LLM agent responsible for code generation and iterative refinement.
* **Tester**: an LLM agent that manages the PBT lifecycle and formulates feedback from property violations.

## Practical Applications
The PGS approach has significant implications for the development of reliable and efficient code generation systems. By leveraging PBT, developers can ensure that generated code satisfies critical properties and invariants, reducing the risk of errors and improving overall code quality. This approach can be applied to a wide range of applications, including web development, software engineering, and data science.
