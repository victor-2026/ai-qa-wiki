# Monitoring for Vibe-Coded Apps
## Summary
Monitoring is a crucial aspect of ensuring the reliability and performance of vibe-coded applications. Despite its importance, monitoring is often overlooked due to the focus on visible features and the "later problem" mentality. This article highlights the need for monitoring, its key concepts, and practical applications to prevent issues like silent API failures and ensure the long-term success of vibe-coded apps.

## Key Concepts
* **Three Layers of Monitoring**:
  1. **Uptime Monitoring**: checking if the app is reachable
  2. **Error Tracking**: identifying and tracking errors and exceptions
  3. **Performance & Health Metrics**: monitoring response times, page load speeds, and resource usage
* **Monitoring Tools**: UptimeRobot, Sentry, Vercel/Netlify Analytics, Datadog, and Grafana Cloud
* **The Vibe Coding Monitoring Blind Spot**: AI tools generate application code but not operational infrastructure, leaving monitoring setup to the developer

## Practical Applications
* Setting up monitoring tools like UptimeRobot, Sentry, and health endpoints can be done in an afternoon
* Implementing structured logging, APM, alerting rules, and synthetic monitoring can provide further insights into app performance
* Monitoring is essential to prevent issues like silent API failures and ensure the long-term success of vibe-coded apps
