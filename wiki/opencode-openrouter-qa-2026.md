## OpenCode + OpenRouter для QA‑тестирования (2026)

**Краткое содержание**  
OpenCode — открытая альтернатива Claude Code, а OpenRouter — универсальный прокси‑хаб, позволяющий переключаться между LLM‑провайдерами без потери совместимости. Их сочетание образует экономичный и гибкий стек, ориентированный на одиночных разработчиков и QA‑инженеров. Ключевое преимущество — отсутствие vendor lock‑in: при изменении цен у одного провайдера достаточно одной команды, чтобы переключиться на другую модель.

---

### Ключевые понятия  

| Понятие | Что это | Почему важно |
|--------|----------|--------------|
| **OpenCode** | OSS‑платформа для генерации и исполнения кода через LLM | Бесплатна, полностью открыта, легко интегрируется в CI/CD |
| **OpenRouter** | Маршрутизатор запросов к более чем 25 бесплатным моделям (Llama 3, Claude 3.5, Llama 3.1‑405b и др.) | Позволяет выбирать оптимальную модель по цене и качеству |
| **No vendor lock‑in** | Переключение модели одной строкой (`/connect openrouter`) | Защищает бюджеты от внезапных ценовых скачков |
| **AGENTS.md** | Описание профиля LLM‑агента, аналог `SKILL.md` | Стандартизирует задачи QA‑агента (анализ, запуск, самовосстановление) |
| **Offline‑режим** | Возможность работы через Ollama без отправки кода в облако | Обеспечивает конфиденциальность и работу в изолированных сетях |

#### Финансовый профиль  

- **OpenCode** — $0 (OSS).  
- **Комиссия OpenRouter** — 5,5 % при оплате картой, 5 % при криптовалюте.  
- **Базовые модели** — более 25 бесплатных вариантов (Llama 3).  
- **Фактические затраты** — $10‑30 /мес при сотнях запусков, против $499 /мес у коммерческого решения Mabl.

### Установка и настройка  

```bash
curl -fsSL https://opencode.ai/install | bash
opencode
/connect openrouter          # подключаем роутер
```

После подключения можно сразу использовать профиль агента из `AGENTS.md`:

```markdown
# Agent Profile: Solo QA Automation Engineer
## LLM Configuration
- Primary: anthropic/claude-3.5-sonnet (OpenRouter)
- Fallback: meta-llama/llama-3.1-405b-instruct
## Context
- Backend: FastAPI (Python)
- Frontend: Playwright (Python)
- Test framework: pytest
## Instructions
1. Сканировать fixtures в ./tests/conftest.py
2. Запускать pytest с полными правами
3. При падении – анализировать трассировку, исправлять, повторять (≤5 циклов)
```

| Цель | Пример команды |
|------|----------------|
| **Исследовательское тестирование** | `opencode "Изучи роуты FastAPI и напиши интеграционные тесты для всех эндпоинтов авторизации, которых нет в /tests"` |
| **Автономный дебаг** | `opencode "Запусти pytest. Если упадет — проанализируй логи, исправь ошибку, добейся зеленого"` |
| **Генерация тестовых данных** | `opencode "Создай json‑фикстуры с граничными значениями для формы регистрации"` |

Эти команды позволяют полностью автоматизировать цикл «написание‑запуск‑исправление», экономя время и снижая количество ручных правок.

### Применение в реальных проектах  

1. **Быстрый старт QA‑потока** – разработчик подключает OpenRouter, задаёт профиль агента и получает готовый набор интеграционных тестов без написания boilerplate‑кода.  
2. **Самовосстанавливающийся CI** – в пайплайне `opencode` автоматически перезапускает падения `pytest`, фиксирует ошибки и сохраняет зелёный статус.  
3. **Защищённая работа с конфиденциальными данными** – при включённом offline‑режиме (Ollama) весь код остаётся локально, а в облако отправляются только промпты.  
4. **Оптимизация бюджета** – при росте цен у Anthropic команда ` /connect openrouter` мгновенно переключает агент на бесплатный Llama 3, сохраняя качество тестов.
