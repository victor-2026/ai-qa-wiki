# Passmark AI Regression Testing Engine
## Summary
Passmark is an open-source AI-powered regression testing framework built on Playwright. It allows tests to be written in natural language, and AI handles locator adaptation when UI changes, reducing regressions by approximately 60% during active frontend refactoring.

## Key Concepts
* **Natural Language Test Definition**: Tests are written in natural language, making it easier for non-technical users to create tests.
* **Auto-Healing Locators**: When UI changes, Passmark detects which step failed, and AI suggests new locators, updating the cache for future runs.
* **Consensus Validation**: Each assertion is verified by multiple models, reducing false positives.
* **Self-Healing**: Passmark can automatically heal failing steps by finding new locators and updating the cache.

## Practical Applications
* **Regression Testing**: Passmark can be used for regression testing, reducing the number of regressions during frontend refactoring.
* **Test Automation**: Passmark can be used to automate testing, reducing the time and effort required for testing.
* **Cost Efficiency**: Passmark is cost-efficient, as it only requires LLM calls on the first run, and subsequent runs use cached steps.
