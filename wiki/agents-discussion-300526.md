### Key Concepts
- **AGENTS.md**: A file intended to provide a cross-vendor standard for AI agents to understand project structures, rules, and guidelines.
- **Boundaries Table**: A table that defines which files or areas can be edited, require permission to edit, or should never be edited.
- **Session Notes/Checkpoint**: Documents that track progress, decisions, and next steps in a project.
- **Code Conventions**: Guidelines for naming, exporting, and using frameworks within a project.
- **Review Guidelines**: Rubrics for automatic review of pull requests.
